# Manual do Usuário - Bruno Airsoft Style

## Introdução
Bem-vindo ao pacote comercial da skill **Bruno Airsoft Style**. Esta ferramenta foi projetada para automatizar e padronizar a presença digital do perfil @brunoairsoft_, garantindo que cada postagem mantenha a estética "Dark Tactical" de elite.

## Como Instalar
1. Copie a pasta `brunoairsoft-style` para o diretório de skills do seu agente Manus.
2. Certifique-se de que o agente tenha permissão de leitura nos arquivos da pasta `templates/`.

## Comandos Principais
Você pode interagir com a skill solicitando:
- *"Gere um post para o feed sobre o novo rifle AEG."*
- *"Crie uma legenda de Reels motivacional seguindo o estilo do Bruno."*
- *"Crie uma imagem tática usando as fotos de referência."*

## Dicas de Ouro
- **Fonte:** Sempre utilize League Gothic em CAIXA ALTA para títulos.
- **Iluminação:** Se o resultado estiver muito claro, peça para "adicionar sombras dramáticas e contraste tático".
- **Legendas:** A skill já aplica automaticamente a estrutura Gancho -> SEO -> Palavras-chave.
